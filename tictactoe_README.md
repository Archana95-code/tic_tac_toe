# Tic-Tac-Toe Game Using Python

## Project Description
This is a simple two-player Tic-Tac-Toe game developed using Python. The game runs in the console. Two players take turns placing X and O on a 3x3 board.

## Features
- Two-player game (X and O).
- Displays a 3x3 game board.
- Checks the winner.
- Checks for a draw.
- Validates player positions.
- Prevents selecting an already occupied position.

## Technologies Used
- Python 3
- VS Code / Jupyter Notebook

## How to Run the Program

1. Install Python 3 on your computer.
2. Copy the Python code.
3. Save the file as `tic_tac_toe.py`.
4. Open the terminal.
5. Run the following command:

```bash
python tic_tac_toe.py
```

## How to Play
1. The game starts with player X.
2. Enter a position from 1 to 9.
3. Player O takes the next turn.
4. Players continue taking turns.
5. The first player to get three marks in a row, column, or diagonal wins.
6. If all positions are filled without a winner, the game ends in a draw.
